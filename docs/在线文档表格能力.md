# 在线文档与表格能力

更新于 2026-09-01。

## 实现策略

在线文档、在线表格、智能表格走 WecomTeam `wecom-cli`，本仓库只提供薄封装和 MCP 工具，不重写企微开放 API。

## 已实现

| 类型 | Python 封装 | MCP 工具 | 能力 |
|---|---|---|---|
| 普通文档 | `online.docs` | `wecom_doc_create`, `wecom_doc_read`, `wecom_doc_write_markdown` | 新旧 CLI 创建/覆写；新版读取线上正文 |
| 本地文档 fallback | `online.local_docs` | `wecom_local_doc_read_path`, `wecom_local_doc_search` | 读取本机已缓存/已下载的文档文件 |
| 智能文档 | `online.docs` | `wecom_smartpage_create`, `wecom_smartpage_import` | 旧版结构化创建；新版空页面创建和 Markdown 导入 |
| 在线表格 | `online.sheets` | `wecom_sheet_create`, `wecom_sheet_info`, `wecom_sheet_get_range`, `wecom_sheet_*` | 新旧 CLI 创建/写入；新版读取单元格范围 |
| 智能表格 | `online.smartsheets` | `wecom_smartsheet_*` | 新旧 CLI 创建、读写子表/字段/记录；旧版不支持记录读取 |
| 自检 | `online.selfcheck` | CLI 命令 | 探测 CLI 代际、授权、服务可用性和 Python 封装覆盖 |

## 当前边界

| 能力 | 原因 |
|---|---|
| 旧 CLI `0.1.x` 读取线上普通文档/表格数据 | 上游未暴露对应读取命令；使用本地 fallback 或升级 CLI |
| 新 CLI `1.1+` 结构化智能主页 `pages` | 新版只接受标题创建或 Markdown 文件导入，旧结构无法无损映射 |
| 本地缓存 fallback | 只能读取本机已下载/已打开文件，可能不是线上最新版 |

## 写操作规则

所有线上写操作都需要显式 `confirmed=True`。确认前必须说明：

1. 目标文档或表格。
2. 写入、更新或删除的内容。
3. 是否可逆，以及是否需要用户人工清理。

## 本地缓存 fallback

当用户提供本地路径，或文档曾作为文件附件下载到本机时，可以用本地 fallback 解析：

```bash
PY=/opt/homebrew/bin/python3
$PY - <<'PY'
from online import local_docs
print(local_docs.search("报价"))
print(local_docs.read_path("/path/to/file.docx"))
PY
```

边界：

- 只读本地文件，不访问线上文档 API。
- 只能读取本机已下载或已打开过的文件。
- 结果可能落后于线上最新版。
- 在线表格/智能表格的结构化数据、字段类型、record_id 仍不能靠本地文件完整替代。
